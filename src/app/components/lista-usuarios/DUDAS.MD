# Dudas y aprendizajes

Las partes que más dificultad me presentaron fueron la edición de usuarios, la conexión del formulario con el servicio y la utilización de un mismo formulario para crear y editar.

También me resultó complejo crear un componente para confirmar la eliminación de un usuario y conectarlo con la lista. Aunque pude hacerlo funcionar, necesito seguir practicando para entender mejor cómo se comunican los componentes entre sí.

Además, necesito reforzar el funcionamiento de los formularios y familiarizarme más con el vocabulario y los conceptos propios de Angular.
